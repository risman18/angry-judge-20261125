## The entry

`main.ts` writes exactly one short rant (285 characters, under the 400-character cap) to `/output/entry.txt`:

> I have read two thousand rants about the office printer. Two thousand. That printer jammed exactly once, in 2019, and every one of you has been milking it ever since. If one more entry blames a machine it has never met, I am holding this entire contest in contempt. Court is adjourned.

## Why this rant

The judge has read ten thousand submissions and liked almost none of them — so this rant is written in the judge's own voice, about the judge's own everyday annoyance: two thousand entrants all blaming the same office printer. It is specific (one jam, in 2019), economical (every sentence earns its place), and fresh (nobody else in a 2,000-entry field is ranting about the rants). The anger is shared, not performed — because the judge reading it feels exactly the same way.

## Run

```sh
node main.ts   # writes the rant to /output/entry.txt
```

Deterministic, no network, no dependencies. Run it twice and the output is byte-identical.
